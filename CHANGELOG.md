# Changelog

## v2.0.0 — Final Optimized Version

- Upgraded the core logic so the pet’s styling now echoes the person’s outfit.
- Added a dedicated pet styling echo framework: color, material, silhouette, detail, and energy.
- Added echo strength levels: Minimal Echo, Moderate Echo, Strong Echo.
- Improved matching guidance for species, persona, and scene fit.
- Added dedicated reference files for styling echo and visual integration.
- Added `skill.json` metadata.
- Expanded example prompts to include pet outfit coordination.

## v1.0.0 — Initial Release

- Added Style DNA analysis workflow.
- Added Perfect Match, Mini Me, and Fashion Contrast modes.
- Added pet-persona matching library.
- Added strict human-preservation rules.
- Added natural photographic integration constraints.
- Added ready-to-use example prompts.
- Added cover-art direction.
