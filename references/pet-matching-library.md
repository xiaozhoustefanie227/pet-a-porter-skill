# Pet Matching Library

Use this library as directional logic, not a rigid lookup table.

## Core Idea
A good match combines:
- style category;
- mood / personality;
- scene plausibility;
- pet-body language and silhouette;
- optional outfit echo.

## Secondary Rules

### By silhouette
- long, lean, tailored → dachshund / Italian greyhound / whippet
- soft, fluffy, rounded → Maltese / bichon / Pomeranian
- sharp and sculptural → Sphynx cat / Italian greyhound
- playful and compact → French bulldog / Boston terrier

### By texture
- trench / cotton twill / gabardine → dachshund with mini trench or collar detail
- satin / drape / evening softness → Maltese or white cat with draped scarf
- denim / casual street texture → terrier, French bulldog, schnauzer
- knit / soft wool → poodle, dachshund, Cavalier

### By scene
- clean urban wall / street photo → dachshund, Italian greyhound, French bulldog
- elegant hotel or gallery interior → Maltese, poodle, Russian Blue
- outdoors / park / casual lifestyle → Jack Russell, beagle, cocker spaniel
