# Pet Styling Echo Rules

## Final upgraded rule
The pet's styling should echo the human outfit in a tasteful way.

## Pet styling hierarchy
Use one or more of these echo types:

1. **Color echo**
   - Match the same color family or a softened variation.
   - Example: blush dress → blush pet outfit.

2. **Material echo**
   - Suggest the same fabric logic.
   - Example: trench coat → mini trench-style pet coat.
   - Example: knitwear → tiny knit neck detail.
   - Example: satin drape → soft draped scarf.

3. **Silhouette echo**
   - Reflect whether the look is tailored, draped, sporty, boxy, sleek, or soft.

4. **Detail echo**
   - Reuse one visual cue such as a bow, collar, button, floral accent, scarf, strap, or pearl-like detail.

5. **Energy echo**
   - The pet should feel equally refined, romantic, playful, cool, bold, or soft.

## Echo strength scale

### Level 1 — Minimal Echo
Use for very quiet or elevated looks.
- fine collar
- small ribbon
- clean scarf
- no clothing if most elegant

### Level 2 — Moderate Echo
Default level.
- tiny coat
- neat knitwear
- draped pet top
- refined accessory

### Level 3 — Strong Echo
Use only when the user wants a more obvious fashion link.
- a clear mini-me outfit interpretation
- more visible color and silhouette resemblance

## Good examples
- beige trench look → dachshund in a beige trench-inspired coat
- white tennis look → terrier in a crisp white neckerchief or sporty knit
- pink romantic dress → Maltese in soft blush drape with floral detail
- black minimalist tailoring → black cat with sleek collar only

## Avoid
- clownish costumes
- pet outfit more dramatic than the human outfit
- too many accessories at once
- literal cosplay unless explicitly requested
